### Gradient of a Tangent
Finding the gradient of a tangent involves the knowledge of 'The First Principle'. Although this is a Level 3 knowledge, it's essential understanding how differentiation works, rather than memorizing formulas. 

<img src="/images/curve-yellow-point.png" style='width: 500px;' />

Lets say we have a function like this (it can be any other function), and we want to find the gradient at when $x=5$ (at the yellow point). However, we have learnt from L2 Coordinate Geometry that you need at least 2 points to find the gradient of a line using the following formula:

$$
\text{Gradient}=\frac{y_{2}-y_{1}}{x_{2}-x_{1}}
$$

So, what we're going to do is plot another point on the graph:

<img src="/images/secant-line-two-points.png" style='width: 500px;' />

Since we have 2 points, we can draw the line, and we can find the gradient of the red line. However, differentiation is about calculating the gradient of a **tangent** line, not a line that intersects the graph twice. 

A tangent line requires the line to intersect the graph at only one point only. However to find the gradient, we must have 2 points. This is where 'limits' come in. 

### Limits
Although limits is a Level 3 content, without limits, differentiation cannot exist.

Limits look like the following notation:

$$
\lim_{ x\space  \to \space 0 } 
$$

We say this as "as $x$ approaches zero". This is basically like an asymptote line. $x$ will *approach* zero, but will never reach zero. 

Another instance,

$$
\lim_{ h \to \infty } 
$$

This is "as $h$ approaches infinity". $h$ will consistently get bigger, as it is approacing $\infty$. 

Going back to the question, and ignoring the axis numbers, lets make the yellow dot on this diagram be have the $x$-coordinate of $x$:

<img src="/images/two-points-labelled.png" style='width: 500px;' />

Using idea of functions, the $y$-coordinate of the yellow dot will be $f(x)$. Therefore, the yellow point will have the coordinates $(x,f(x))$.

Now, lets let the horizontal distance between the yellow point and the pink point be $h$.
This will mean that the $x$-coordinate of the pink point will be $x+h$, and the $y$-coordinate would be $f(x+h)$. Therefore the pink point will have the coordinates $(x+h,f(x+h))$ like this:

<img src="/images/points-fxh-labelled.png" style='width: 500px;' />

Now, lets apply our knowledge from coordinate geometry, using the gradient formula of:

$$
\text{Gradient}=\frac{y_{2}-y_{1}}{x_{2}-x_{1}}
$$

If we let 
$y_{2}=f(x+h)$, 
$y_{1}=f(x)$,
$x_{2}=x+h$,
$x_{1}=x$,

we will get the following equation:

$$
\text{Gradient}=\frac{f(x+h)-f(x)}{(x+h)-x}
$$

However, we need the gradient of a tangent. So, this is where limits come in. 

We have defined the horizontal distance between the yellow and pink points to be $h$. Lets use limits, to make $h$ approach zero. 

<img src="/images/limit-h-approaches-zero.png" style='width: 500px;' />

It would look very similar to this. This means that we have two points on the graph that can make a gradient, but the points are so close to each other that we can deem it as being one point.

Now, we add the limit notation to the gradient formula:

$$
\boxed{\text{Gradient}=\lim_{ h \to 0 } \frac{f(x+h)-f(x)}{h}}
$$

We call the above boxed formula, "The First Principles of Differentiation".

Now, instead of calling the gradient, the "Gradient" as seen from the boxed formula, we call this the **Derivative**, noted as $f'(x)$, or $\frac{dy}{dx}$.


$$
\boxed{f'(x)=\frac{dy}{dx}=\lim_{ h \to 0 } \frac{f(x+h)-f(x)}{h}}
$$


You can choose which expression to use between $f'(x)$ and $\frac{dy}{dx}$, in Level 2. However, in Level 3 Calculus, you'll be strongly advised to use $\frac{dy}{dx}$.
