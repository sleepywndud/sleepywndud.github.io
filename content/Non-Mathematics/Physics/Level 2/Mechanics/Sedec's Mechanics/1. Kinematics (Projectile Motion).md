# Introduction
In L2 Mechanics, there will *100%* be a question on kinematics. 

The kinematic questions are structured in a way that you have to find a variable (e.g. the question could ask you to find the distance that something travels). 

In L2 Mechanics, the context is 90% going to be on 'projectile motion' -- the motion on a projectile. The projectile could be an apple, a javelin, a rugby ball, hocky puck, etc...

These formulas below are called 'kinematic formulas', and are provided in the formula sheet. The first two are common sense, whereas the rest are the actual formulas that we use in questions.

$$

$$

</td>
<td>

$$

<tr>

$$

</td>

To actualy make use of these formulas, we need to know what the variables mean.\
$v$ is velocity, and $v_{i}$ is the INITIAL velocity (hence it has the little $i$ below the $v$!). Likewise, $v_{f}$ is the FINAL velocity.\
$d$ is the distance.\
$t$ is the time.

Using these 5 variables: $v_{i}$ $v_{f}$ $a$ $d$ $t$, we can solve ANY kinematics equations that is given in L2 Mechanics. 

> [!note] NOTE: If you have ANY 3 variables from $v_{i}$ $v_{f}$ $a$ $d$ $t$, you can get ALL other variables!
> Also make sure that you're confident with algebraic manipulation, since these questions require some algebraic manipulations.

# Applications (1d)

EXAMPLE QUESTION (NZQA 2025 91171):
> A rugby player accelerates uniformly from rest at $0.680 \ ms^{-2}$ and runs $22.0 \ m$.
> How long did it take to run the $22.0 \ m$?

When we get a question like this, the absolute first thing that we should do is write down the variables ($v_{i}$ $v_{f}$ $a$ $d$ $t$) that we're given.

In the example question, we are given the distance of $22.0 \ m$, the acceleration of $0.680 \ ms^{-2}$. However, we need one more variable to perform any calculation. This is (kind of..) hidden. "from rest" gives us the last variable -- from rest means that it starts with its speed being zero, so we know that $v_{i}=0$. 

Now that we have $a$, $d$, $v_{i}$, we have to choose a formula from the formulas above that has the three variables, and $t$, since we're calculating for $t$.

The best would be to use $d=v_{i}t + \frac{1}{2}at^{2}$ since we have all the variables that we're given + the variable that we're looking for. 

Now time for algebra!

$$
d=v_{i} \cdot t + \frac{1}{2} \cdot a \cdot t^{2}
$$


$$
22=0 \cdot t + \frac{1}{2} \cdot a \cdot t^{2}
$$


$$
22=\frac{1}{2} \cdot 0.68 \cdot t^{2}
$$


$$
44 = 0.68 \cdot t^{2}
$$


$$
t^{2}=\frac{44}{0.68}
$$


$$
t=\sqrt{ \frac{44}{0.68} }
$$


$$
t=8.043996665 \text{ seconds}
$$


$$
\boxed{t=8.0 \text{ seconds (2sf)}}
$$


Note that this is only an achieved question. The excellence-level calculation questions often involve the use of 2+ formulas, or you have to perform multiple calculations. 

However, following the principles of:
1. Write down what variables you're given (you need THREE variables to perform any calculation)
2. Pick a formula that has all three variables that you're given, and the variable you're looking for
..you can solve any question, and get the excellence mark for that question.

> Almost every time, we are given an angle and the diagonal component like the image above, and this is a TRAP!\
